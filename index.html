Quiénes Somos

Somos un equipo de cinco estudiantes de Ingeniería Civil Informática de la Universidad Autónoma, formados en la asignatura de Desarrollo Web. Nuestra misión es construir sitios estáticos, eficientes y accesibles, garantizando código estructurado, diseño responsivo y despliegue impecable en servidores Nginx.

Misión

Desarrollar sitios web estáticos con código limpio y estructurado, utilizando tecnologías como HTML, CSS y Bootstrap, desplegados eficientemente mediante contenedores Docker y servidores Nginx.

Fortalezas

  • Maquetación semántica y CSS avanzado
  • Gestión ágil con metodologías Scrum
  • Control de calidad y pruebas
  • Despliegue con contenedores Docker

Reflexiones del Equipo

Lecciones aprendidas por cada integrante del equipo Los Poco Serios

Damon Murray

Durante esta actividad, mi principal aprendizaje se centró en la arquitectura visual y técnica de un sitio web. Al asumir el rol de QA y Front-end, me di cuenta de la importancia de mantener un código limpio y estructurado, separando la lógica de Bootstrap del diseño estético mediante el CSS personalizado.

Nicolás Contreras

Durante esta actividad aprendí mucho sobre el desarrollo web y de lo importante que es hacer un backlog ordenado, ya que al principio no sabía muy bien cómo distribuir las tareas ni cómo coordinar con mis compañeros.

Cristóbal Garrido

Este proyecto nos demostró que la organización del equipo es tan importante como la programación. GitHub y el control de versiones fueron nuestros pilares: mantener una estructura ordenada y utilizar ramas nos permitió desarrollar distintas secciones en paralelo de forma segura.

Ítalo Osorio
