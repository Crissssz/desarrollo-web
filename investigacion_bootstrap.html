Bootstrap

Framework CSS, diseño responsivo, grillas y componentes

¿Qué es Bootstrap?

Bootstrap es el framework CSS más popular del mundo. Creado originalmente por Twitter, es una biblioteca de código abierto que facilita el desarrollo de sitios web responsivos y modernos.

Proporciona una colección de componentes preestilizados, un sistema de grillas potente y clases utilitarias que permiten crear interfaces atractivas sin necesidad de escribir CSS desde cero.

En este sitio utilizamos Bootstrap 5.3 cargado mediante CDN (Content Delivery Network), lo que significa que se carga directamente desde los servidores de jsDelivr sin necesidad de instalar archivos localmente.

Ventajas de Utilizar un Framework CSS

Ahorro de tiempo

Componentes ya diseñados y listos para usar, eliminando la necesidad de escribir CSS desde cero.

Diseño responsivo

El sistema de grillas se adapta automáticamente a dispositivos móviles, tablets y escritorio.

Consistencia visual

Todos los componentes siguen una guía de diseño coherente y profesional.

Comunidad activa

Miles de desarrolladores contribuyen, documentan y resuelven problemas constantemente.

Sistema de Grillas: container, row y col

El sistema de grillas de Bootstrap se basa en tres elementos fundamentales:

.container

Contenedor principal que centra el contenido y le da un ancho máximo responsivo.

.row

Fila horizontal que agrupa columnas. Utiliza flexbox internamente.

.col-md-*

Columna que ocupa un número de las 12 columnas disponibles.

<div class="container">
  <div class="row">
    <div class="col-md-6">Columna izquierda (50%)</div>
    <div class="col-md-6">Columna derecha (50%)</div>
  </div>
</div>

Componentes Utilizados en Este Sitio

Navbar

Barra de navegación responsiva que se colapsa en dispositivos móviles.

Cards (Tarjetas)

Contenedores flexibles para mostrar información agrupada.

Grid System

Sistema de 12 columnas con container, row y col.

Buttons

Botones con múltiples estilos y tamaños predefinidos.

Badges

Etiquetas pequeñas para tecnologías y categorías.

Accordion

Paneles colapsables para contenido extenso.

Diferencia entre Bootstrap y CSS Personalizado

Bootstrap
  • Componentes predefinidos y listos para usar.
  • Sistema de grillas responsivo automático.
  • Diseño rápido y consistente.
  • Dependencia de la biblioteca externa.
CSS Personalizado
  • Control total sobre cada estilo.
  • Sin dependencias externas.
  • Diseño único y diferenciado.
  • Requiere más tiempo de desarrollo.

En este sitio combinamos ambos enfoques: usamos Bootstrap para la estructura, grillas y componentes básicos, y CSS personalizado para el estilo visual minimalista.
