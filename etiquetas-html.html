Etiquetas HTML de Uso Común

Etiquetas frecuentes para estructura y contenido

Estas son las etiquetas HTML más frecuentes para dar estructura y contenido a una página, sin implicar por sí mismas un significado semántico particular.

Cuándo usarla: para títulos y subtítulos, respetando el orden jerárquico (un solo <h1> por página).

Ejemplo en el sitio: el título principal usa <h1 class="display-4">.

Cuándo usarla: para párrafos de texto corrido; nunca para simular espaciado con párrafos vacíos.

Ejemplo en el sitio: el texto introductorio de cada tarjeta .card.

Cuándo usarla: para cualquier enlace, interno o externo.

Ejemplo en el sitio: los enlaces de la navbar.

Cuándo usarla: para incrustar imágenes; siempre con atributo alt descriptivo.

Ejemplo en el sitio: fotos de perfil en integrantes.html.

Cuándo usarla: <ul> para listas sin orden específico, <ol> cuando el orden importa.

Ejemplo en el sitio: listas de fortalezas y habilidades en las tarjetas.

Cuándo usarla: contenedores genéricos sin significado semántico. <div> es de bloque, <span> es en línea.

Ejemplo en el sitio: el grid de Bootstrap usa <div> con clases de columna.

Cuándo usarla: exclusivamente para datos tabulares reales (filas y columnas comparables).

Ejemplo en el sitio: tabla de comandos Docker en instalacion.html.

Cuándo usarla: <form> agrupa campos de entrada; cada <input> debe llevar su <label> asociado.

<form>
    <label for="nombre">Nombre</label>
    <input type="text" id="nombre" name="nombre" class="form-control">
    <button type="submit" class="btn btn-outline-dark">Enviar</button>
</form>
