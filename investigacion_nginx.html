Construcción y Publicación con Nginx

Cómo desplegar el sitio web utilizando Docker y Nginx

Importante: Asegúrate de tener Docker Desktop instalado antes de seguir estos pasos. Consulta la página de instalación de Docker si es necesario.

¿Qué es Nginx?

Nginx (pronunciado "engine-x") es un servidor web de alto rendimiento que puede funcionar como servidor HTTP, proxy reverso, balanceador de carga y servidor de correo electrónico. Es uno de los servidores web más utilizados del mundo, conocido por su velocidad y bajo consumo de recursos.

En este proyecto, Nginx se utiliza para servir los archivos estáticos del sitio web (HTML, CSS, imágenes) dentro de un contenedor Docker.

Contenido del Dockerfile

El archivo Dockerfile define cómo se construye la imagen Docker del sitio:

FROM nginx:alpine

COPY index.html /usr/share/nginx/html/index.html
COPY integrantes.html /usr/share/nginx/html/integrantes.html
COPY investigaciones.html /usr/share/nginx/html/investigaciones.html
COPY investigacion_html.html /usr/share/nginx/html/investigacion_html.html
COPY investigacion_css.html /usr/share/nginx/html/investigacion_css.html
COPY investigacion_bootstrap.html /usr/share/nginx/html/investigacion_bootstrap.html
COPY docker-instalacion.html /usr/share/nginx/html/docker-instalacion.html
COPY docker-comandos.html /usr/share/nginx/html/docker-comandos.html
COPY investigacion_nginx.html /usr/share/nginx/html/investigacion_nginx.html
COPY reflexion.html /usr/share/nginx/html/reflexion.html

COPY css/ /usr/share/nginx/html/css/
COPY pages/ /usr/share/nginx/html/pages/
COPY imágenes/ /usr/share/nginx/html/imágenes/

EXPOSE 80

Explicación de las Instrucciones

FROM nginx:alpine

Define la imagen base: Nginx versión Alpine (ligera). Descarga automáticamente la imagen desde Docker Hub.

COPY [origen] [destino]

Copia archivos del equipo al contenedor. La destino /usr/share/nginx/html/ es donde Nginx busca los archivos del sitio.

EXPOSE 80

Indica que el contenedor expone el puerto 80 (puerto HTTP estándar).

COPY css/ ...

Copia carpetas completas con todos los archivos de estilos, páginas e imágenes.

Comandos de Construcción y Ejecución

Construir la imagen
docker build -t los-poco-serios .

El parámetro -t asigna un nombre a la imagen. El punto . indica que el Dockerfile está en el directorio actual.

Ejecutar el contenedor
docker run -d -p 8080:80 los-poco-serios

El parámetro -d ejecuta en segundo plano. -p 8080:80 mapea el puerto.

Mapeo de Puertos

El mapeo de puertos -p 8080:80 funciona así:

Puerto del host (8080)

El puerto en tu computador al que accedes desde el navegador.

Puerto del contenedor (80)

El puerto interno donde Nginx está escuchando.

Resultado

Accedes al sitio en http://localhost:8080

Evidencia de Funcionamiento

Al ejecutar los comandos correctamente, el sitio debería estar disponible en http://localhost:8080.

  • El navegador muestra la página principal del sitio.
  • La navegación entre páginas funciona correctamente.
  • Los estilos CSS se aplican adecuadamente.
  • Las imágenes se cargan sin problemas.

En la terminal, el contenedor aparece ejecutándose con el comando:

docker ps
