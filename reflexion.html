Herramientas Utilizadas

GitHub

Control de versiones, gestión de ramas, pull requests y merge de código.

Discord / WhatsApp

Comunicación constante del equipo, coordinación de reuniones y resolución de dudas.

Dificultades Encontradas

Conflictos de merge en Git

Al trabajar en la misma rama o en ramas similares, surgieron conflictos al intentar unir los cambios de diferentes integrantes.

Coordinación de horarios

Como estudiantes universitarios, coordinar horarios para reuniones presenciales o virtuales fue un desafío constante.

Soluciones Aplicadas

  • Git: Establecimos una rama principal (main) y ramas de desarrollo para cada funcionalidad, facilitando la integración.
  • Comunicación: Mantuvimos un canal activo en Discord/WhatsApp para reportar cambios y coordinar tareas.
  • Documentación: Cada integrante documentó su trabajo para facilitar la comprensión del código.
  • Reuniones periódicas: Agendamos reuniones semanales para revisar el avance y resolver problemas.

Aprendizajes

HTML y CSS

Aprendimos a crear estructuras semánticas, estilos responsivos y diseño moderno con Bootstrap.

Docker y Nginx

Descubrimos cómo contenedores Docker simplifican el despliegue de sitios web estáticos.

Trabajo en equipo

La comunicación efectiva y la organización son clave para el éxito de cualquier proyecto.

Control de versiones

Git y GitHub son herramientas esenciales para el desarrollo colaborativo.

Importancia de la Colaboración

Este proyecto nos demostró que el desarrollo web moderno es un esfuerzo colaborativo. Cada integrante aportó sus habilidades únicas, y la combinación de conocimientos permitió crear un producto final que ninguno podría haber logrado solo.

La organización, la comunicación y el uso de herramientas adecuadas fueron fundamentales para superar los obstáculos y alcanzar nuestros objetivos.

Reflexiones Individuales

Damon Murray

Durante esta actividad, mi principal aprendizaje se centró en la arquitectura visual y técnica de un sitio web. Al asumir el rol de QA y Front-end, me di cuenta de la importancia de mantener un código limpio y estructurado, separando la lógica de Bootstrap del diseño estético mediante el CSS personalizado. Logré profundizar en el uso de clases dinámicas y plantillas compartidas para evitar el código repetitivo, logrando implementar una estética unificada en todo el proyecto. Por el lado del trabajo en equipo, aprender a manejar ramas (branches) independientes en Git fue fundamental, ya que al principio implementé cambios directamente al main y si bien no hubo problemas, necesitaba crear mi propia branch para desarrollar sin miedo a romper el trabajo de mis compañeros. Finalmente, comprender cómo nuestras interfaces se integran y despliegan utilizando contenedores Docker fue clave para poder ver el panorama completo del desarrollo web actual.

Nicolás Contreras

Durante esta actividad aprendí mucho sobre el desarrollo web y de lo importante que es hacer un backlog ordenado, ya que al principio no sabía muy bien cómo distribuir las tareas ni cómo coordinar con mis compañeros, pero luego de juntarnos en llamada me quedó más claro el panorama. Otra cosa que rescato de este trabajo es que aprendí a usar Git y GitHub para mantener un orden con mis compañeros, ya que al principio me enredaba un poco el tema de las ramas y los commits. Pude aprender sobre HTML y CSS principalmente, además de conocer nuevas herramientas como Docker y Nginx, las cuales eran importantes para publicar nuestra página.

Cristóbal Garrido

Este proyecto nos demostró que la organización del equipo es tan importante como la programación. GitHub y el control de versiones fueron nuestros pilares: mantener una estructura ordenada y utilizar ramas nos permitió desarrollar distintas secciones en paralelo de forma segura, sin el riesgo de dañar el código principal. Además, mantener un historial limpio nos facilitó enormemente la integración del trabajo, dejándonos como gran lección que dominar estas herramientas colaborativas es indispensable para nuestro desarrollo profesional, al mismo nivel que tecnologías como Docker o Nginx.
