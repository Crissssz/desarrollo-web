CSS

Definición, formas de aplicar, selectores, clases e identificadores

¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje de estilos que se utiliza para definir la presentación visual de un documento HTML. Mientras que HTML se encarga de la estructura y el contenido, CSS controla colores, fuentes, espaciados, disposition y diseño responsivo.

Fue creado en 1996 por el W3C y es una de las tres tecnologías fundamentales de la web junto con HTML y JavaScript.

Importancia de CSS en el Desarrollo Web

Separación de contenido y presentación

Permite modificar el diseño sin alterar la estructura HTML del sitio.

Diseño responsivo

Adapta el sitio a diferentes tamaños de pantalla usando media queries.

Consistencia visual

Un solo archivo CSS puede controlar el estilo de todo el sitio web.

Mejora la experiencia de usuario

Un diseño atractivo y funcional retiene a los visitantes.

Contenido, Estructura y Presentación

En el desarrollo web existen tres capas fundamentales que trabajan juntas:

Contenido (HTML)

Es la información que se muestra: textos, imágenes, enlaces, datos. Es el "qué" del sitio web.

Estructura (HTML semántico)

Organiza el contenido en secciones lógicas usando etiquetas como <header>, <nav>, <main>, <section>. Es el "cómo" se organiza.

Presentación (CSS)

Define la apariencia visual: colores, fuentes, espaciados, disposición. Es el "cómo se ve" el sitio.

Formas de Aplicar CSS

1. En línea (inline)

Se aplica directamente en la etiqueta HTML usando el atributo style.

<p style="color: blue;">Texto azul</p>
2. Interno (interno)

Se define dentro de una etiqueta <style> en el <head> del HTML.

<style>
  p { color: blue; }
</style>
3. Externo (externo)

Se enlaza un archivo .css independiente con <link>.

<link rel="stylesheet"
  href="styles.css">

Selectores, Clases e Identificadores

Selectores básicos

Seleccionan elementos por etiqueta.

p { color: red; }
h1 { font-size: 2rem; }
Clases (.)

Reutilizables en múltiples elementos.

.card { padding: 20px; }
<div class="card">
Identificadores (#)

Únicos en la página.

#header { background: blue; }
<div id="header">

Modelo de Caja (Box Model)

Cada elemento HTML es un rectángulo compuesto por cuatro áreas:

Margen

Espacio exterior que separa el elemento de otros.

Borde

Línea que rodea el elemento.

Relleno

Espacio interior entre el borde y el contenido.

Contenido

El texto o imagen que muestra el elemento.

.elemento {
  margin: 20px;      /* Margen exterior */
  border: 1px solid black;  /* Borde */
  padding: 15px;     /* Relleno interior */
  width: 300px;      /* Ancho del contenido */
}

Ejemplos de Estilos en Este Sitio

Este sitio utiliza CSS personalizado combinado con Bootstrap. Algunos ejemplos:

  • Navbar minimalista: Fondo blanco semitransparente con efecto de desenfoque.
  • Tarjetas: Bordes redondeados y sombras sutiles al pasar el mouse.
  • Botones: Fondo negro con transiciones suaves.
  • Tipografía: Space Mono para títulos, Inter para el cuerpo del texto.
  • Badges: Colores pastel para tecnologías (HTML azul, CSS verde, Bootstrap lila).
