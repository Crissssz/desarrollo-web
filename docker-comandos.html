Comandos Docker

Sintaxis, descripcion y ejemplos de los comandos Docker mas usados.

Comando Uso Principal Sintaxis Descripcion Ejemplo
docker --version Consultar la version instalada docker --version Muestra la version del Docker Engine instalado. docker --version → Docker version 24.0.7
docker run hello-world Ejecutar una imagen de prueba docker run [IMAGEN] Descarga y ejecuta un contenedor de prueba para verificar la instalacion. docker run hello-world
docker images Listar imagenes locales docker images Muestra todas las imagenes descargadas en el sistema. docker images
docker ps Mostrar contenedores en ejecucion docker ps Lista los contenedores que estan corriendo actualmente. docker ps
docker ps -a Mostrar todos los contenedores docker ps -a Lista todos los contenedores, incluyendo los detenidos. docker ps -a
docker build Construir una imagen desde un Dockerfile docker build -t [NOMBRE] . Construye una imagen personalizada a partir de un Dockerfile. docker build -t mi-sitio .
docker run Crear y ejecutar un contenedor docker run -d -p [PUERTO]:[PUERTO] [IMAGEN] Crea un contenedor nuevo desde una imagen y lo ejecuta. docker run -d -p 8080:80 mi-sitio
docker stop Detener un contenedor docker stop [CONTENEDOR] Detiene un contenedor en ejecucion de forma graceful. docker stop mi-contenedor
docker start Iniciar un contenedor detenido docker start [CONTENEDOR] Reinicia un contenedor que fue detenido previamente. docker start mi-contenedor
docker rm Eliminar un contenedor docker rm [CONTENEDOR] Elimina un contenedor detenido permanentemente. docker rm mi-contenedor
docker rmi Eliminar una imagen docker rmi [IMAGEN] Elimina una imagen local que ya no se necesita. docker rmi hello-world
docker logs Consultar registros de un contenedor docker logs [CONTENEDOR] Muestra los logs (salida estándar y errores) de un contenedor. docker logs mi-contenedor
docker exec Ejecutar comandos dentro de un contenedor docker exec -it [CONTENEDOR] [COMANDO] Permite ejecutar comandos interactivos dentro de un contenedor en ejecucion. docker exec -it mi-contenedor sh
