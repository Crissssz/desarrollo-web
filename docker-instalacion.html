Instalacion de Docker

Requisitos, pasos de instalacion en Windows y evidencia de ejecucion.

Que es Docker Desktop?

Docker Desktop es una aplicacion de escritorio para Windows, Mac y Linux que facilita la creacion, configuracion y ejecucion de contenedores Docker. Incluye el Docker Engine, Docker CLI, Docker Compose, Docker Hub y herramientas de Kubernetes.

Proporciona una interfaz grafica intuitiva para gestionar contenedores, imagenes, redes y volumenes sin necesidad de usar exclusivamente la linea de comandos.

Requisitos Basicos de Instalacion

  • Sistema operativo: Windows 10 o 11 (version 64-bit con WSL 2 habilitado).
  • Memoria RAM: Minimo 4 GB recomendados (8 GB o mas ideal).
  • Disco duro: Al menos 4 GB de espacio libre.
  • Virtualizacion: Habilitar virtualizacion BIOS/UEFI (VT-x o AMD-V).
  • WSL 2: Windows Subsystem for Linux version 2 (se instala automaticamente durante la configuracion).

Pasos para Instalar Docker Desktop en Windows

  1. Descargar Docker Desktop desde https://www.docker.com/products/docker-desktop/.
  2. Ejecutar el instalador Docker Desktop Installer.exe.
  3. Marcar la opcion "Use WSL 2 instead of Hyper-V" (recomendado).
  4. Hacer clic en OK y esperar a que complete la instalacion.
  5. Reiniciar el computador cuando se solicite.
  6. Despues del reinicio, abrir Docker Desktop y esperar a que el servicio inicie (icono verde en la bandeja).

Evidencia: Comando hello-world

Despues de instalar Docker Desktop, se puede verificar la instalacion ejecutando:

docker run hello-world

Este comando descarga la imagen hello-world desde Docker Hub y ejecuta un contenedor que muestra un mensaje de confirmacion:

Hello from Docker!
This message shows that your installation appears to be working correctly.

To generate this message, Docker took the following steps:
 1. The Docker client contacted the Docker daemon.
 2. The Docker daemon pulled the "hello-world" image from the Docker Hub.
 3. The Docker daemon created a new container from that image which runs the
    executable that produces the output you are currently reading.
 4. The Docker daemon streamed that output to the Docker client, which sent it
    to your terminal.

Si este mensaje aparece, la instalacion fue exitosa.

Evidencia: Docker Desktop Funcionando

Al abrir Docker Desktop, se muestra el panel principal con:

  • Containers: Lista de contenedores en ejecucion o detenidos.
  • Images: Catalogo de imagenes descargadas localmente.
  • Volumes: Volumenes persistentes creados.
  • Settings: Configuracion de WSL 2, puertos, recursos y Docker Engine.

Cuando el indicador en la esquina inferior izquierda muestra "Engine running" en verde, Docker esta listo para usar.
