¿Qué es Bootstrap?

Bootstrap es un framework CSS de código abierto diseñado para desarrollar interfaces web responsivas y modernas de manera rápida y sencilla.

Creado originalmente por Mark Otto y Jacob Thornton en Twitter en 2011, ahora es mantenido por la comunidad open source.

HTML, CSS, JS Licencia MIT Open Source v5.3
Línea del tiempo
2011 - Nacimiento

Creado por Mark Otto y Jacob Thornton en Twitter como "Twitter Blueprint"

2012 - Bootstrap 2

Se introduce el sistema de grid de 12 columnas e iconos

2013 - Bootstrap 3

Adopción del diseño "mobile-first" y glyphicon icons

2018 - Bootstrap 4

Flexbox, cards, utilidades SCSS y nuevos componentes

2021 - Bootstrap 5

Sin jQuery, CSS custom, mejoras de accesibilidad y nuevos componentes

¿Para qué sirve Bootstrap?

Descubre por qué millones de desarrolladores eligen Bootstrap todos los días

Prototipado Rápido

Construye interfaces completas en horas en lugar de días. Los componentes predefinidos te ahorran mucho tiempo de desarrollo.

100% Responsivo

Tu sitio se adapta automáticamente a cualquier dispositivo: móviles, tablets y escritorios con el sistema de grid.

Cross-Browser

Funciona perfectamente en todos los navegadores modernos: Chrome, Firefox, Safari, Edge y más.

Personalizable

Modifica colores, espaciado y estilos con variables Sass o CSS personalizadas para que se adapte a tu marca.

Gran Documentación

Documentación oficial completa con ejemplos en vivo, snippets de código y tutoriales para cada componente.

Comunidad Masiva

Más de 27k estrellas en GitHub, miles de plantillas y una comunidad activa que resuelve dudas.

Grid System (Sistema de Grilla)

El corazón de Bootstrap: un sistema de 12 columnas para crear diseños flexibles
